# PayPlus Documentation System

This directory contains the operating architecture used to create, review, integrate, and maintain PayPlus documentation.

[DOC-00](../00-foundation/doc-00-documentation-governance.md) remains the sole documentation governance authority and sole owner of the ranked source-of-truth hierarchy. The documents here supplement DOC-00 and subject frameworks; they do not replace governance, product requirements, or domain ownership.

| Document | Classification | Use |
| --- | --- | --- |
| [Documentation Architecture Map](documentation-architecture-map.md) | Canonical navigation artifact | Identify authority, ownership, routing, dependencies, and permitted document types. |
| [Documentation Development Workflow](payplus-documentation-development-workflow.md) | Canonical lifecycle workflow | Apply the complete Documentation Lifecycle and every lifecycle stage and gate. |
| [PayPlus Work Command Language](payplus-work-command-language.md) | Normative command-interface reference | Interpret Founder work commands and route them to the canonical lifecycle without duplicating its rules. |
| [Parallel-Agent Documentation Procedure](payplus-parallel-agent-documentation-procedure.md) | Optional execution procedure | Coordinate approved parallel agents, workstreams, worktrees, consolidation, and parallel review. |
| [DOC-07 Design Specification Specialist Guide](payplus-doc-07-design-specification-specialist-guide.md) | Specialist guide | Apply DOC-07-specific authoring methods, matrices, and specialist checks. |
| [Prototype Design and Validation Specialist Guide](payplus-prototype-design-validation-specialist-guide.md) | Specialist guide | Apply prototype-specific planning, build, validation, status, and evidence methods. |

Start with the Architecture Map for routing. When the Founder uses a named work command, use the Work Command Language to interpret it, then apply the Documentation Development Workflow for lifecycle control. Load only the procedure or specialist guide whose trigger applies. Detailed rules remain in their canonical owner and are not restated here.
